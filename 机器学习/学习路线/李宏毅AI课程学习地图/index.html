李宏毅老师的 AI 课程学习指南

发表于2026-11-01|更新于2026-11-02|机器学习学习路线

李宏毅老师（Hung-yi Lee）是国立台湾大学教授，他的研究涉及机器学习、深度学习、语音处理和语言理解，长期公开分享相关教学课程。他的课程讲得细致，也很有趣，经常从一个具体问题讲起，先解释为什么需要这个方法，再逐步讨论模型、公式和训练过程。他还会把动漫人物和故事情节带进课堂，例如，他会通过宝可梦能力值预测、宝可梦与数码宝贝分类等案例讲解回归和分类；在2024 年课程第 5 讲的模型协作专题中，则从《葬送的芙莉莲》的故事引出多个语言模型如何配合完成任务。这些诙谐幽默的例子，让抽象概念有了具体的角色和情境，更容易理解和记忆。即使没有看过相关作品，也可以跟着他对情节的介绍理解问题。

了解李宏毅老师：个人主页与公开资料
  • 个人官网：个人简介、研究方向与公开教学资料。
  • 课程入口：通过 Course 菜单查看不同系列和学期的课程、课件与作业。
  • 官方 YouTube 频道与播放列表：按课程系列观看视频。
  • Research 与 Publication：研究主题与论文成果。

我们希望通过李宏毅老师的课程系统地学习 AI，但他的课程比较多，不同年份的内容也有所重叠。例如，同样是 Machine Learning，早期课程主要介绍回归、分类和神经网络，近年的课程则更多讨论大模型训练、推理和 Agent。如果按照年份逐一学习，会花不少时间在重复的内容上；直接从新课开始，又可能缺少一些基础知识。

为了更有顺序地学习，我们可以先了解各门课程的侧重，再把不同年份的相关章节串起来，从基础知识逐步学到大模型和 Agent：

  • 表 1：学期课程总览：我整理了李宏毅老师开设的诸多课程的类别、名称、开课学期、主要内容和官网入口，方便了解不同课程版本的侧重，选择适合自己的课程。
  • 表 2：课程学习路径：我按照知识之间的连贯性将不同课程的不同章节串联起来，还整理了交互学习地图，可按节点查看课程并记录进度。

1. 课程全景：每门课适合学什么

李宏毅老师的 AI 相关课程主要可以分为六个系列：Linear Algebra、Machine Learning、MLDS、DLHLP、Generative AI 和 GenAI-ML，内容从数学基础延伸到机器学习、深度学习和生成式 AI。

其中，MLDS 的全称是 Machine Learning and having it deep and structured，主要涉及深度学习及相关进阶内容；DLHLP 是 Deep Learning for Human Language Processing，侧重语音与语言处理。

ML19 机器学习 Machine Learning 2019 春 在回顾回归、分类和神经网络的同时，重点展开异常检测、可解释性、对抗攻击、终身学习、元学习和模型压缩，后期引入 Transformer 与 BERT。
ML20 机器学习 Machine Learning 2020 春 以 15 项作业串起学习过程，从回归、分类、CNN 和序列模型走向自编码器、GAN 与迁移学习，同时练习可解释性、对抗攻击、模型压缩、元学习和强化学习。

ML22 深度学习主干 Machine Learning 2022 春 围绕图像、序列、生成与自监督任务学习深度学习，并配套 15 项作业；专题进一步讨论语音与图像自监督、训练与验证、NLP 对抗攻击及元学习。
ML23 生成式 AI 与大模型 Machine Learning 2023 春 从 ChatGPT 的预训练与使用方式出发，比较 Prompting 和微调，讨论模型与数据规模、Diffusion、工具调用和自主规划；作业仍覆盖回归、CNN、Transformer 等深度学习基础。
ML25 大模型进阶 Machine Learning 2025 春 围绕大模型能力如何形成和改进展开，讨论预训练与对齐、微调遗忘、推理与评估、模型编辑和融合，也分析 Agent、模型内部机制与 Mamba；配套 RAG、训练和微调实验。
ML26 Agent 与模型改进 Machine Learning 2026 春 以 OpenClaw 说明 Agent 的运行方式，深入上下文管理、协作、Harness、自我纠错与自我提升；同时讲解 Flash Attention、KV Cache 和位置编码，连接系统能力与模型效率。
DS15 深度学习进阶 MLDS 2015 秋 将神经网络训练与结构化预测结合起来：前半部分讲 DNN、反向传播和 RNN，后半部分深入结构化 SVM、序列标注与图模型，并延伸到语言建模和 Attention。
DS17 深度学习进阶 MLDS 2017 春 聚焦如何生成相互关联的序列与图像，学习计算图、语言模型、条件生成和 GAN，再延伸到强化学习与模仿学习；作业包括语言建模、视频描述、动漫图像生成和聊天机器人。
DS18 理论、生成与强化学习 MLDS 2018 春 先从表达能力、优化和泛化理解深度网络，再学习 Seq2seq、Attention、GAN 与强化学习；其中 GAN 和 Policy Gradient、PPO、Q-Learning 等内容展开较细。
HLP20 语音与语言处理 DLHLP 2020 春 围绕机器如何处理语音与文字展开：语音部分涵盖识别、转换、分离、合成和说话人验证；文本部分讨论 BERT、非自回归生成、风格迁移、问答与对话系统。
GA24 生成式 AI 入门 Generative AI 2024 春 从生成式 AI 的用途和提示方法讲起，逐步解释预训练、指令微调、RLHF、Transformer 与 Agent，再讨论能力评估、可解释性、安全及图像和视频生成。
GM25 生成式 AI 与 ML 入门 GenAI-ML 2025 秋 先认识生成式 AI、上下文工程与能力评估，再回到机器学习、神经网络训练和大模型学习过程；后续讨论终身学习、影像与语音生成，配套 RAG、分类、微调和生成作业。

看过这些课程，我们可以发现：不同年份的课程既有延续，也有侧重。线性代数与早期机器学习课程帮助我们打基础，近年的课程逐渐深入大模型和 Agent，MLDS、DLHLP 则提供理论、生成模型和语音语言处理等方向的专题。实际学习时，可以选择一门基础课作为起点，再从其他课程中补充需要的章节。接下来的学习路径和交互地图，就是沿着这个思路把相关内容连接起来。

2. 课程学习路径：我接下来学什么

了解各门课程的内容后，还需要确定具体的学习顺序：先学哪些知识，哪些章节可以接着学，遇到不熟悉的概念时又该回到哪里补充。本章从这些课程中选出相关章节，按照知识之间的前后关系，整理出一条从基础到大模型与 Agent 的学习路径。

这条路径沿着“数学基础 → 机器学习 → 深度学习与 Transformer → 大模型 → RAG 与 Agent”展开。我们先理解模型怎样从数据中学习，再学习语言模型的训练与生成，最后把检索、工具和反馈接入实际任务。图像生成、语音处理和理论研究作为延伸方向，可以在具备相应基础后按兴趣深入。

学习说明：标签、资料与基础准备
  • 学习标签：“主线”建议优先学习；数学“基础”可以先自测，已掌握的部分直接跳过。“补充”和“选修”按需要展开，“按需补”用于补齐前置知识，“实践”需要动手完成。
  • 资料标记：每个单元都附有学习目标和资料链接，YT1、YT2 表示同一单元的不同视频。
  • 数学准备：除了线性代数，还会用到求导、偏导数、链式法则，以及条件概率、期望和方差。学习梯度下降、反向传播和概率模型时，如果推导跟不上，可以针对这些概念回补，不必等到学完整套数学课程才开始。
  • 编程准备：实践需要基本的 Python 和数组运算能力，能读取数据、检查张量形状，并写出训练与验证的基本流程。不熟悉 PyTorch 或 Colab 时，可以结合 ML22 的入门教程边学边练。

2.3. 机器学习基本方法

2.4. 深度学习与 Transformer

先理解神经网络怎样计算、反向传播怎样求梯度，再学习优化器、损失函数和 Normalization，解决网络如何训练的问题。随后通过 CNN、RNN 和 Seq2Seq 了解图像与序列建模，沿 Attention → Self-Attention → Transformer 理解现代语言模型的结构。C16 继续补充位置编码，解释模型如何区分序列中的位置，以及长输入会带来什么问题。

3. 学习建议

3.1. 从零开始，先学会训练模型，再进入大模型与 Agent

可以先从 A01—A07 开始，再学 B01—B05、B10，完成一个回归或分类实验。接着学习 C01—C14 和 C16，理解神经网络训练、序列建模、Transformer 与位置编码。C03、C12 可以作为计算图和 Attention 的补充；需要学习降维时，再补 A08、A10、A11 和 B08。

进入大模型后，按 D01 → D02 → D04 → D05 → D06 学习自监督、BERT、GPT、预训练和指令微调；在 D09 的 RLHF 之前补齐 D07、D08，最后通过 D10 理解预训练与对齐的能力和局限。

准备实践时先看 E06，再学习 E01、E02、E04、E05、E07—E09，了解模型适配、推理能力、评估与效率。之后按 F01 → F02 → F05 → F06 → F07 → F09 → F10 → F11 → F13 → F14 → F15 进入提示工程、RAG 与 Agent。完成基本流程后，再选择协作、自我提升或其他感兴趣的专题。

3.2. 已有机器学习与深度学习基础，补齐大模型与 Agent

如果已经理解 Self-Attention、Transformer 和自回归生成，可以从 D05 → D06 → D09 → D10 开始。位置编码和长输入不熟悉时补 C16，Policy Gradient 和 PPO 不熟悉时在 D09 前补 D07、D08。

之后先学 E06，再按 E01 → E02 → E04 → E05 → E07 → E08 → E09 补充模型适配、推理能力、评估和生成效率。Agent 部分沿用上一节的 F01—F15 路线；需要多模型协作时加学 F03、F12，希望研究持续能力提升时再学 F16、F17。

3.3. 关注模型训练与能力改进

重点学习 D05—D10、E01—E05，弄清不同训练阶段使用什么数据、优化什么目标，以及新任务的提升是否伴随旧能力退化。实验前通过 E06 准备评估集，之后再看模型编辑 E12、模型融合 E13 和内部机制 E15。涉及多 GPU 训练时，先学 E08，再看 E11；对 Mamba 等架构感兴趣时，在 C10、C14、E09 的基础上学习 E14。

实践可以从 GM25 的 HW7：Finetuning LLM开始，再结合该课程的 HW8 或 ML26 的 HW5：Finetuning without Forgetting研究遗忘。如果更关心生成效率，可以沿 E08 → E09 → E10 学习，并参考 ML26 的 HW3：LLM Fast Inference开展实验。

3.4. 关注 Agent 应用与工程

先理解 D04 中语言模型的生成方式，再用 E06 建立任务评估方法，就可以进入 F01、F02、F05—F07、F09—F11 和 F13—F15。实践可以围绕一个文档问答或资料分析任务分三步展开：

  1. 直接问答：准备一组真实问题和评分规则，记录模型的回答、依据与失败原因。
  2. 加入检索和工具：在同一组问题上比较直接问答、RAG、工具调用的效果，分别记录检索失败与生成失败。
  3. 连续执行任务：逐步加入上下文整理、失败重试和反馈，记录成功率、耗时、调用次数与成本。每次只改变一项主要机制，判断它是否值得保留。

GM25 的 HW2：Build a Basic RAG System适合练习第二步；ML26 的 HW2：AI Agent as an AI Engineer 与 HW8：Test-Time Scaling可以用于进一步练习工具执行和测试时计算。基础流程稳定后，再尝试多 Agent 和自我提升：前者需要检查协作收益能否抵消额外开销，后者还要验证后续任务的能力是否提升。

3.5. 图像、语音与理论方向

图像生成可以从 G01—G05 开始，再通过 G06 深入扩散模型的数学原理，结合 G07 比较不同生成策略。语音方向先学 G08—G10，再看 G11，理解语音识别、合成与语音语言模型之间的联系。

想进一步理解网络为什么有效，可以看 G12、G13；强化学习可沿 D07 → D08 → G14 展开。迁移与任务适应从 B11 开始，再学习 G16、G18。可解释性与对抗攻击见 G15；遇到存储或算力限制时，可以结合 G17 的模型压缩和 E08—E10 的推理加速学习。

如果希望在 B 站观看，可以搜索“李宏毅＋课程名称＋年份”，或加上章节标题查找视频，再与官网目录核对。也希望李宏毅老师能在 B 站开设官方账号，方便大家观看完整课程、查找资料和了解更新。
