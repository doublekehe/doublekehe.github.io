Python 常用数据类型

图 1：Python 常用数据类型可以分为标量、序列、映射和集合等类别。

Python 中的每个值都有类型。数字 10 是 int，文本 "Python" 是 str，由多个元素组成的 [1, 2, 3] 是 list。类型决定了数据能保存什么、支持哪些操作，以及创建后能否修改。

Python 是动态类型语言。变量无需预先声明类型，它只是在运行时引用某个对象。

2. 空值与布尔类型

2.1 NoneType

None 用来表示“没有值”或“尚未产生结果”，它是 NoneType 的唯一实例。判断一个值是否为 None 时通常使用 is，不使用 ==。

没有显式 return 语句的函数也会返回 None。

2.2 bool

bool 只有 True 和 False 两个值。它主要出现在条件判断和比较结果中。

数值 0、None、空字符串和空容器的布尔值为 False；大多数其他对象的布尔值为 True。

3. 数字类型

Python 有三种主要数字类型：整数 int、浮点数 float 和复数 complex。

3.1 int

int 表示整数，Python 整数的精度不受固定位数限制，只受可用内存限制。

3.2 float

float 使用二进制浮点数表示小数。某些十进制小数无法被二进制精确表示，因此会出现微小误差。

判断浮点数是否接近时，可以使用 math.isclose()。

3.3 complex

complex 表示复数，虚部使用 j 或 J 书写。

4. 字符串 str

str 用来存储 Unicode 文本。字符串有顺序、允许重复字符，支持索引和切片。

字符串是不可变对象，不能直接修改某个位置的字符。

replace()、upper() 和 strip() 等字符串方法也不会修改原字符串，它们会返回新字符串。

5. 列表、元组与 range

5.1 list

list 是最常用的可变序列。它有顺序、允许元素重复，也允许混合存储不同类型的对象。

虽然列表可以混合存储多种类型，但数据用途一致时，元素类型保持统一通常更容易理解和处理。

5.2 tuple

tuple 是不可变序列，适合表示一组创建后不应改变的值。

5.3 range

range 表示不可变的整数序列。它只保存起点、终点和步长，不会预先将所有整数存入内存。

6. 字典 dict

dict 以键值对的形式存储数据。每个键必须唯一，通过键可以快速查找对应的值。字典会保留键的插入顺序。

使用 user["city"] 读取不存在的键会引发 KeyError。get() 可以在键不存在时返回默认值。

字典的键必须是可哈希对象。数字、字符串和由可哈希元素组成的元组可以作为键，列表和字典不可以。

7. 集合 set 和 frozenset

set 是可变集合，元素不重复，也不支持按下标取值。它常用于去重、成员检查和集合运算。

集合不保证元素的显示顺序，上面的输出顺序只是便于阅读的表示。

创建空集合必须使用 set()。{} 创建的是空字典。

frozenset 是不可变集合。当其元素都可哈希时，frozenset 本身也可以作为字典键或另一个集合的元素。

8. 二进制数据类型

8.1 bytes

bytes 是不可变字节序列，常用于文件、网络协议和图像等二进制数据。文本需要通过编码转换为字节。

8.2 bytearray

bytearray 是可变字节序列，适合需要原地修改二进制数据的场景。

9. 可变对象与不可变对象

可变对象可以在原地修改，不可变对象发生“修改”时实际上会创建新对象。

表 2　常用类型的可变性
类型性质 常用类型
不可变 NoneType、bool、int、float、complex、str、tuple、range、frozenset、bytes
可变 list、dict、set、bytearray

可变对象被多个变量引用时，通过其中一个变量修改对象，其他变量也会观察到变化。

如果需要一个独立的列表，可以创建浅拷贝。

浅拷贝只复制最外层容器。容器内部仍然引用同一个可变对象时，需要根据场景考虑 copy.deepcopy()。

10. 类型检查与转换

type() 可以查看对象的具体类型。进行类型判断时，通常使用会考虑继承关系的 isinstance()。

12. 总结

选择数据类型时，先看数据是单个值还是一组值，再看是否需要保留顺序、是否允许重复，以及创建后是否需要修改。

list 适合可变的有序数据，tuple 适合固定的有序数据，dict 通过键组织数据，set 用于去重和成员检查。类型本身就在表达数据的用途，合适的类型能让后续操作更直接。
