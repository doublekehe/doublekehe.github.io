Python 常用内置函数

图 1：内置函数对输入数据进行处理并生成输出。

Python 内置函数可以直接调用，不需要先执行 import。例如，len() 计算对象长度，sum() 对数字求和，enumerate() 在遍历时同时产生索引和元素。

1. 常用函数速查

2. 输入输出与对象检查

2.1 print() 和 input()

print() 将对象输出到控制台。sep 控制多个对象之间的分隔符，end 控制结尾字符。

input() 始终返回字符串。需要数字时，应显式转换类型。

2.2 len()、type() 和 isinstance()

len() 返回容器中的元素数量。type() 返回对象的具体类型，isinstance() 还会考虑继承关系，因此更适合业务代码中的类型判断。

id() 返回对象在当前运行期内的唯一标识，callable() 用来判断对象能否像函数一样调用。

3. 数值计算与聚合

3.1 abs()、round()、pow() 和 divmod()

round() 采用“向最接近的偶数舍入”规则处理恰好位于中间的数值。浮点数还受二进制表示误差影响，不宜将它当作精确的十进制舍入工具。

3.2 sum()、min() 和 max()

min() 和 max() 支持 key 参数，可以按对象的某个字段比较。

4. 迭代与序列处理

4.1 range() 和 enumerate()

range(start, stop, step) 生成一个整数序列，其中 stop 不包含在结果中。

enumerate() 比手动维护索引更直接，start 用来指定起始编号。

4.2 zip()、map() 和 filter()

zip() 按位置组合多个可迭代对象。默认情况下，它会在最短的输入耗尽时停止。

map() 对每个元素执行同一个函数，filter() 保留使条件为真的元素。

zip()、map() 和 filter() 返回迭代器。迭代器只在需要时生成元素，且消费完后不会自动回到开头。

4.3 sorted() 和 reversed()

sorted() 返回一个新列表，不会修改原对象。

sorted() 是稳定排序。多个元素的 key 值相同时，它们保持原来的相对顺序。

4.4 all() 和 any()

all() 要求所有元素都为真，any() 只要一个元素为真就返回 True。

对空的可迭代对象，all([]) 返回 True，any([]) 返回 False。

5. 类型转换

许多内置类型也可以像函数一样调用，用来创建对象或转换类型。

类型转换并不保证成功。例如，int("3.14") 会引发 ValueError，因为这个字符串不是合法的整数字面值。处理外部输入时应捕获可能出现的转换异常。

6. 字符、进制与对象表示

ord() 将单个 Unicode 字符转换为码点，chr() 执行反向转换。

bin()、oct() 和 hex() 分别返回整数的二进制、八进制和十六进制字符串。

str() 倾向于生成面向用户的文本，repr() 倾向于生成便于调试的明确表示。

7. 动态属性操作

getattr()、setattr() 和 hasattr() 适合属性名在运行时才能确定的场景。

getattr(object, name, default) 中的 default 可以在属性不存在时避免 AttributeError。dir() 则返回对象的属性和方法名称列表，常用于交互式探索和调试。

8. 使用 open() 读写文件

open() 返回文件对象。通常将它放在 with 语句中，代码块结束后文件会自动关闭。处理文本文件时，建议明确指定编码。

9. 容易忽略的问题

9.1 不要覆盖内置函数名

变量名不宜使用 list、str、sum、max 或 id 等内置名称。

9.2 谨慎使用 eval() 和 exec()

eval() 求值表达式，exec() 执行动态 Python 代码。如果输入可由用户控制，攻击者可能借此执行任意代码。普通的字符串解析、JSON 解析和类型转换都有更明确的工具，不应为了方便直接使用 eval()。

10. 总结

掌握内置函数的重点是知道它们的输入、返回值和是否会产生迭代器。len()、sum() 和 isinstance() 直接返回结果；map()、filter()、zip() 和 reversed() 返回可消费的迭代器；sorted() 则构造一个新列表。把这些区别理清，就能在大多数日常代码中选对函数。
